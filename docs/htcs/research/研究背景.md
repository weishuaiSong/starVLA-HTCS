# 研究背景

VLA 模型默认仅消费当前观测，难以应对长时程任务、遮挡追踪与失败恢复，因此历史记忆压缩成为 2025–2026 年 VLA 研究的核心问题之一。

现有路线大致可归为四类：

- **多尺度记忆**：MEM、π0.7、MemoryVLA、ReMem-VLA 把秒级视觉与分钟级语义分别承载。
- **外置检索记忆**：MemER、PrediMem、MAP-VLA 用 keyframe / 软提示库 + 高层规划器按任务检索历史。
- **隐式 token 压缩**：HAMLET、SD-VLA 在网络内部把多帧观测压成少量 token。
- **视频编码先验**：HiF-VLA 把 MPEG 运动向量作为 VLA 输入特征；同期 video LLM 侧 CoPE-VideoLM、OneVision-Encoder 也用 MV / 残差 / I-P 结构做 token 压缩，三条路线在不同社区同时合法化。

它们共同的三个盲点是：（1）任务条件化只发生在**读取层**，压缩过程本身仍任务无关；（2）所有 codec 路线**全部任务无关**；（3）分层 VLA 的记忆只经由"子任务文本"影响低层动作，**低层策略仍是单帧马尔可夫的**。

## 本工作

本工作提出 **HTCS（Hierarchical Task-Conditioned Saliency）**：基于 HEVC codec 原语（I-frame RGB + 二维 MV + Residual energy），用**双 granularity 语言条件化**完成历史压缩。

- **参数级**：用语言派生的权重 α(ℓ)、β(ℓ)、γ(ℓ) 与目标方向向量 v_tgt(ℓ) 调制 saliency 公式（含 MV 方向项），决定"看哪种运动"。
- **结构级**：用语言派生的 K 个 query 与稀疏 patch 集做 cross-attention，输出摘要词元，决定"看哪些 patch"。

压缩后的摘要词元直接进入动作策略。整个流水线**仅依赖语言信号、不使用 proprioception**，对跨平台与人类示范视频兼容。
